# JRMJ Games — site e política de privacidade

Arquivos estáticos para o repositório https://github.com/jvictor-82/jrmj-games-site. Sem instalação de pacotes ou build.

## Revisar antes de publicar

- O texto corresponde ao Entre Letras atual, sem anúncios. Não reutilizar sem revisão na versão com publicidade.
- Confirmar as práticas de atendimento/retensão descritas e a identificação pública JRMJ Games. Se a Play Console usar outro responsável, adequar a identificação de forma coerente.
- Política preparada com base no código do app; não substitui a verificação dos SDKs, backup e declarações de Segurança dos dados do binário final.
- Não há botões de download: o jogo ainda não tem URL de loja confirmada.

## Enviar pelo navegador

1. No repositório, escolher Add file → Upload files.
2. Enviar index.html, styles.css e a pasta entre-letras com privacidade.html. Preservar a estrutura; não criar uma pasta extra jrmj-games-site dentro do repositório.
3. Fazer commit na branch main.
4. Em Settings → Pages, selecionar Deploy from a branch, main e /(root), e salvar.
5. Aguardar o deploy e abrir os dois endereços em janela privada, também no celular.

Endereços esperados, ainda não verificados como publicados:

- https://jvictor-82.github.io/jrmj-games-site/
- https://jvictor-82.github.io/jrmj-games-site/entre-letras/privacidade.html

Após conferir a política publicada, ativar seu link em Configurações no aplicativo. Não cadastrar uma URL indisponível na Play Console.
